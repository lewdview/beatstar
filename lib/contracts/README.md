## 📜 Smart Contract Specification (`PIM.sol`)

Located at `contracts/PIM.sol`:

### 1. Contract Overview
* **Standard**: ERC-721 Non-Fungible Token with OpenZeppelin `Ownable`, `ECDSA`, `MessageHashUtils`, and `Base64`.
* **Contract Name**: `Poetry in Motion: th3v4ult` (`PIM`)
* **Deployment Target**: **Base Mainnet (Chain ID `8453` / Hex `0x2105`)** / Base Sepolia Testnet (`84532`).

### 2. On-Chain Dynamic Metadata (`tokenURI`)
The contract generates Base64 JSON metadata **100% on-chain** without relying on centralized IPFS gateways for metadata JSON:
* **JSON Attributes**:
  * `Day`: Integer day index (1–365) with 3-digit zero-padding in name (e.g. `Day 001`).
  * `Rarity`: `common`, `uncommon`, `rare`, `legendary`, `mythic`.
  * `Edition`: Global mint print index.
  * `Proof`: Verification signature or certification (e.g. `proof_of_first`).
  * `Lifecycle`: `original` vs `echo`.
  * `Echo Generation`: Generation index (0 for Gen 0 originals, 1–3+ for Echo decays).
  * `image`: URL pointing to the card artwork.
  * `animation_url`: URL pointing to the full audio / session stem stream.

### 3. Minting Pathways
1. **Administrative / Backend Direct Mint (`mintCard`)**:
   - Authorized backend operator address calls `mintCard` to sponsor gas for Web2 and onboarding players.
2. **Signature-Authorized User Mint (`mintCardWithSignature`)**:
   - Player executes transaction directly, paying gas on Base while providing an EIP-712 / ECDSA cryptographic signature generated by the authorized backend minter.

## 🛠️ Hardhat Commands

```bash
# Compile Solidity contracts with Cancun EVM settings
npx hardhat compile

# Run Hardhat test suite
npx hardhat test

# Deploy to Base Sepolia Testnet
npx hardhat run scripts/deploy.ts --network base-sepolia

# Deploy to Base Mainnet
npx hardhat run scripts/deploy.ts --network base-mainnet

# Verify contract on BaseScan
npx hardhat verify --network base-mainnet <CONTRACT_ADDRESS> <INITIAL_OWNER_ADDRESS>
```
